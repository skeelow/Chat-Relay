## Task
M3.2b per the packet (D12): Stop and Resume, with the live smoke.
## Result
- Store: paused()/setPaused() — "1" or absent, DELETE on clear; survives a
  restart (tested). markStatus keeps a note on pending_approval rows (see
  Surprises) so the stop notes ride on rows like the restart notes.
- Engine Stop: one synchronous pass — persist paused, queued → pending
  "stopped — approve again after you resume", delivering → pending "stopped
  before confirmation — it may already have arrived"; per-row delivery_update,
  pause_update, then interrupt to codex; stop twice is a no-op. Stopped:
  approve ignored+logged, hello flushes nothing, late acks ignored, captures
  store. Resume delivers nothing. Snapshot carries paused; restarts stay stopped.
- Codex adapter: interrupt → turn/interrupt on the relay thread's in-progress
  turns; tracks turn/start's id, interruptTargets(turns/list) with none (pure,
  tested); best effort, logged, chained behind the delivery chain; no other threads.
- GUI: red Stop button; stopped → banner "Stopped — nothing will be delivered
  until you resume", button reads Resume, Approve disabled with a title; state
  only from snapshot.paused / pause_update; textContent only.
