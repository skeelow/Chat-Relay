# M1.2 fixes — engine robustness and auth hygiene

Task: M1.2 fixes from the review — `relay/engine.ts` and `tests/engine.test.ts` only.
Result: pass

Fixes, each with its test:

1. **Socket errors no longer crash the engine.** Every client socket gets `ws.on('error')` as the first thing in the connection handler; it logs one line — `[engine] socket error: <err.message>`, never the token — and lets ws close the socket. A persistent `server.on('error')` logger is attached after listening.
   Test: a ws client completes the handshake, then a masked text frame containing invalid UTF-8 is written directly to the underlying socket (`0x81 0x82 …`); the engine logs the socket error, and a fresh adapter then auths, hellos as `codex`, and its capture is stored and broadcast to the GUI. The test run shows the error line itself, proving the path was exercised.

2. **A replaced adapter is not reported as disconnected.** `hello` now nulls the older socket's participant BEFORE closing it, so its close handler broadcasts nothing, and any status/captured frames it races in are ignored by the existing `participant === null` checks.
   Test: A hellos `codex`, B hellos `codex`; after A's close fires plus 200 ms the GUI's status sequence is exactly `idle, idle` (no `disconnected`); a capture raced on A after B's hello is neither stored nor broadcast; closing B broadcasts `disconnected` exactly once.

3. **An empty or malformed token file is regenerated.** `loadOrCreateToken` only trusts a trimmed 64-hex file; anything else is overwritten with a fresh random token.
   Test: an empty token file → `{type:'auth', token:''}` closes 4401; the file then holds 64 hex characters and the fresh token authenticates normally.

4. **Any frame before auth closes 4401.** Enforced once at the top of the message handler — including non-JSON frames — and the now-redundant per-case `!state.authenticated` checks were removed (the auth case keeps its re-auth guard).
   Test: `{type:'captured', body:'x'}` on a fresh connection → close code 4401 and nothing stored.

5. **Hygiene.** `RelayChat/` added to `.gitignore` (the token lands there when APPDATA is unset). A listening failure (e.g. EADDRINUSE) now closes the store before rejecting, and `main()` catches it and prints one line — `[engine] cannot listen on 127.0.0.1:8787: <err.code>` — then exits 1.

Protocol, store, and read-only behaviour unchanged; the auth frame stays exactly `{type:'auth', token}`.

Suite result: **24 tests, 0 failures** (13 store + 11 engine).

Files changed: `relay/engine.ts`, `tests/engine.test.ts`, `.gitignore`, `docs/status/m1.2-fixes.md`.
