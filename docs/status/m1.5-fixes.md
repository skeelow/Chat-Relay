# m1.5-fixes — GUI/engine/store review fixes (S1, N1–N5)

## Task
Apply the M1.5 review packet: S1 pill CSS, N1 monotonic ULID, N2 GUI→hello guard,
N3 honest connection states, N4 navigation locks, N5 the restoreQueue persist race.

## Result
- S1: pill CSS now keys on the raw `data-status` (`selectors_stale`, `awaiting_approval`);
  the visible label uses `replaceAll('_', ' ')`. `data-status` stays the raw value.
- N1: `ulid()` increments the previous random part within the same millisecond
  (Crockford carry), so id order equals capture order.
- N2: the engine closes a socket that sends `hello` after `gui_hello` with 4400
  'GUIs cannot be adapters' — mirror of the existing gui_hello guard.
- N3: "engine connected" shows only when the snapshot arrives; a 4401 close shows
  "token rejected — restart the engine or check %APPDATA%\RelayChat\token" and the
  2 s retry loop continues either way.
- N4: `setWindowOpenHandler(() => ({action: 'deny'}))` + `will-navigate` preventDefault.
- N5: `restoreQueue()` ends with `persistQueue()` — a capture arriving mid-restore can
  no longer overwrite the restored items in storage.session. Background BUILD_MARKER
  bumped to 2026-10-19.3 (marker convention: every rebuild identifies itself live).
