## Result
- Store: searchMessages — parameterised case-insensitive substring over
  bodies; %, _ and the escape character escaped (a bare % matches only
  literal percent signs); newest `limit` first; total past the limit.
- Engine: `search` (GUI-only, trimmed 1–200 chars, asking socket alone,
  newest 100 newest first) and `export` (Markdown, newest 5,000 oldest
  first). Stale requestIds: the GUI's pure state machine (app/src/search.ts)
  drops them; snippetAround builds the previews.
- relay/export.ts (pure): bodies verbatim in a fence one backtick longer
  than the body's longest run (unbreakable), Delivery lines per row, cap
  note at 5,000. One narrow IPC `relay:save-export` writes UTF-8; the
  preload adds only saveExport + reportTrayCounts — no generic file API.
- Tray: icons drawn in code (trayicon.ts, 16×16 PNGs via zlib; green dot,
  red-dot alert while approvals wait), Show window/Quit, click toggles,
  tooltip "Relay Chat — N pending, M approvals waiting" fed by renderer
  IPC. Close hides to the tray — the engine is a separate process, so a
  hidden GUI never stops the relay.
- Window state: windowstate.ts — bounds validated against attached
  displays, saved debounced on move/resize and on close to
  window-state.json in userData; corrupt file ignored. The relay
  settings already persist in the engine (M4.2).
- Pause/resume is the existing Stop/Resume (D17-1) — nothing new built.
